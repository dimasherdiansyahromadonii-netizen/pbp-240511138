# Analisis Komparatif Platform

## 1. Tabel Analisis Platform Web, Desktop, dan Mobile

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | Java, C++, C#, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Client-server, diakses melalui browser | Aplikasi berjalan pada sistem operasi komputer | Aplikasi berjalan pada sistem operasi smartphone |
| Cara distribusi | Melalui browser menggunakan URL | Melalui installer atau toko aplikasi | Melalui Google Play Store atau Apple App Store |
| Keunggulan | Mudah diakses, tidak perlu instalasi khusus pada perangkat pengguna | Dapat memanfaatkan sumber daya komputer dan berjalan tanpa internet untuk fitur tertentu | Praktis, mudah dibawa, dan dapat menggunakan GPS serta kamera |
| Keterbatasan | Fitur tertentu bergantung pada browser dan koneksi internet | Perlu instalasi dan penyesuaian terhadap sistem operasi | Memiliki keterbatasan baterai, ukuran layar, dan kompatibilitas perangkat |
| Contoh aplikasi | Gmail versi web, Google Docs | Microsoft Word Desktop, Visual Studio Code | WhatsApp, Google Maps |

## 2. Kesimpulan

Platform Web cocok untuk aplikasi yang dapat diakses melalui browser. Platform Desktop cocok untuk aplikasi yang digunakan pada komputer. Platform Mobile cocok untuk aplikasi yang digunakan melalui smartphone. Pemilihan platform harus disesuaikan dengan kebutuhan pengguna dan fungsi aplikasi.
